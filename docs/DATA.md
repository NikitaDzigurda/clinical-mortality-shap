# Аналитические данные

## Единица наблюдения и исход

Строка таблицы — аналитическая запись/госпитализация, а не обязательно уникальный пациент. `row_id` — технический номер строки, отсчитываемый с нуля; `group_id` — техническая группа повторных записей одного пациента. Группы ОКС сформированы в исходной локальной подготовке по равенству нормализованных ФИО; в сосудистой базе группировка приблизительная. В экспорт не включены ФИО и таблицы соответствий. Тёзки, ошибки написания и неполные первичные записи могут давать ошибки группировки.

`hospital_death`: 1 — отметка смерти, 0 — отсутствие соответствующей отметки. Для ОКС 43 положительных записи, для сосудистой задачи 55 положительных записей в 51 группе. Пятьдесят пять сосудистых отметок нельзя автоматически трактовать как 55 независимых умерших пациентов. Версия исхода сосудистой задачи уточнена автором по анкете; старые и новые метки не объединяются. Точный временной горизонт и клиническая интерпретация уточнённых исходов должны соответствовать окончательной рукописи, а не выводиться из имени столбца.

CSV имеет кодировку UTF-8, разделитель — запятая, десятичный знак — точка. Пустое поле означает пропуск. Его нельзя автоматически заменять нулём. Численные величины сохранены такими, какими поступили в расчёты. Единицы «ед. базы» намеренно не заменены неподтверждёнными единицами измерения.

## ОКС

Файл: `data/acs.csv`. Состав: 906 строк; 892 группы; 43 положительных исхода; 15 предикторов. Полный машинный словарь — `data/acs_dictionary.csv`.

| Поле | Содержание | Кодирование |
|---|---|---|
| age | Возраст | годы |
| male | Мужской пол | 1 — мужской; 0 — женский |
| mi | Инфаркт миокарда | 0/1 по клинической кодировке |
| st_elevation | ОКС с подъёмом ST | 0/1 |
| tag | Максимальный ТАГ | ммоль/л |
| ms | Метаболический синдром | 0/1; неизвестное — пропуск |
| killip | Класс Killip | 1–4; неизвестное — пропуск |
| low_ef | Зарегистрированный признак ФВ ≤45% | 0/1; отсутствие записи не доказывает нормальную ФВ |
| crp | С-реактивный белок | мг/л |
| ckd | Хроническая болезнь почек | 0/1 по клинической кодировке |
| pre_tlt | Догоспитальная тромболитическая терапия | 0/1 |
| af | Фибрилляция предсердий | 0/1 |
| pci | Интервенционное лечение | исходные коды 1/2 объединены в 1, коды 0/3 — в 0 |
| grace | Оценка GRACE | баллы |
| diabetes | Сахарный диабет | 0/1; неизвестное — пропуск |

При подготовке восстановлены исходные пропуски из первичных таблиц вместо использования заранее импутированной матрицы. В локальной сверке 93 значения ТАГ различались между версиями источников; для анализа использованы значения исходной электронной таблицы. Для 13 неоднозначных исходных кодов исход ОКС принят по клинически подготовленному CSV и прежнему анализу автора. Это ограничения исходной документации, а не признаки, исправленные при публикационном экспорте.

Для максимального ТАГ и части вмешательств время регистрации не установлено. Поэтому все 15 полей нельзя автоматически объявлять доступными при поступлении. Высокая важность индикатора отсутствия СРБ может отражать особенности обследования и регистрации, а не действие самого показателя.

## Сосудистая когорта

Файл: `data/vascular.csv`. Состав: 548 строк; 511 групп; 55 положительных записей; 14 предикторов. Словарь — `data/vascular_dictionary.csv`.

| Поле | Содержание |
|---|---|
| age_years | Возраст, годы |
| ef_percent | Фракция выброса, % |
| creatinine_value | Креатинин, единицы базы |
| total_cholesterol | Общий холестерин, единицы базы |
| ldl_mmol_l | Холестерин ЛПНП, ммоль/л |
| glucose_value | Глюкоза, ммоль/л |
| crp_value | СРБ, единицы базы |
| egfr_value | СКФ, единицы базы |
| bmi | Индекс массы тела, кг/м² |
| female | Женский пол, 0/1 |
| prior_vascular_surgery | Предшествующая сосудистая операция, 0/1 |
| mi_history | Инфаркт миокарда в анамнезе, 0/1 или пропуск |
| stroke_history | ОНМК в анамнезе, 0/1 или пропуск |
| vascular_group | Клиническая сосудистая группа, 0/1/2 |

Группы: 0 — периферические артерии (253 записи, 34 отметки смерти); 1 — АБШ/аневризма аорты (101 запись, 16 отметок); 2 — сонные артерии (194 записи, 5 отметок). Их объединение в одну прогнозную задачу не устраняет клиническую неоднородность.

Время доступности признаков при поступлении подтверждалось автором исходного анализа, но не независимой сверкой временных меток. Данные содержат исправления пяти числовых ячеек, ошибочно интерпретировавшихся как даты Excel; публикационный набор содержит уже использованные в актуальном расчёте численные значения. Сырые значения и журналы, связывающие их со строками приватных источников, не экспортируются.

## Технический экспорт

Из аналитического набора удалено поле `source_row`; ФИО, контакты, даты и номера документов не включались. К существующим техническим `group_id` добавлены отдельные постоянные смещения по когортам; сохранены равенство групп и порядок их сортировки, используемый алгоритмом разбиения. Это не криптографическое обезличивание. Сохранение сортировки обеспечивает совпадение исходных групповых разбиений при тех же версиях библиотек. Ни исходные значения групп, ни их соответствия реальным пациентам для работы с репозиторием не требуются.

Признаки, целевой исход и маски пропусков проверены на точное совпадение с использованными в расчётах матрицами. Порядок аналитических строк сохранён ради соответствия опубликованным OOF, разбиениям и массивам SHAP. Отдельные OOF-таблицы имеют несколько строк на запись: по семействам, вариантам и повторениям проверки. Это не дополнительные клинические наблюдения.

Данные остаются чувствительными клиническими микроданными без прямых идентификаторов. Формальная оценка риска повторной идентификации не выполнена. Репозиторий не содержит утверждения о юридически подтверждённой анонимности или автоматически предоставленных правах на распространение.
